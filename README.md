# Xileades Claude marketplace

Internal marketplace for Xileades / Groupe X-ARC.

## Install

```
/plugin marketplace add Xileades/claude-marketplace
/plugin install qonto-api-toolkit@xileades
/plugin install payfit-api-toolkit@xileades
/plugin install pennylane-api-toolkit@xileades
```

Each plugin ships its skills, its PowerShell library and its pitfalls catalogue.
API keys are never stored in these repositories: each user keeps a local
`tokens.json` (see each repository's README).
